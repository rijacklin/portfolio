LedgerAPI

A financial transaction REST API. Built to explore systems design and inspired by the idempotent design of the Stripe API. The API models money as a value object, derives balances from the ledger at request time, and retries colliding writes with randomized exponential backoff. Unit and integration tests run in CI.

  • C#
  • ASP.NET Core
  • Entity Framework Core
  • SQLite
  • xUnit

DELTA Visualizations Plugin

A Moodle plugin that visualizes real-time course data. This plugin served as the implementation component of my undergraduate capstone learning analytics research project. It implements Ajax-like dynamic chart refreshes, alongside a random forest model, trained using Python, that analyzed the relationships between learning behaviours and student learning outcomes.
